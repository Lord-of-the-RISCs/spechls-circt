-annotate-timing

Add timing annotation to task operations.

Options

-task        : Name of task to inline
-clockPeriod : Target clock for scheduling.
-target      : Target to map timing with.
-targetsFile : Json file with targets timing.

-expose-control-flow-speculation

Add speculation mechanism into a task.

Options

-targetTask           : Name of task to inline
-clockPeriod          : Target clock for scheduling.
-target               : Target to map timing with.
-targetsFile          : Json file with targets timing.
-probabilityThreshold : Minimum probability of speculation configurations
-traceFileName        : Profiling trace file.
-wcetModel            : Stop speculation insertion at the generation of the wcet module.
